Technologies Used:
- HTML
- CSS
- PHP
- MySQL
- phpMyAdmin
- InfinityFree

Usage:
Press any movement button: Forward, Backward, Left, Right, Stop
The selected command is saved in the database.
Open `get_state.php` to retrieve the latest command in JSON format.

Database:
The project uses a table named `robot_state` to store:
Robot command
Last update time

Result:
The project was successfully deployed on InfinityFree. Commands are stored correctly in the database and can be retrieved through the API endpoint in JSON format.
